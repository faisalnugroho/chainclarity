About

ChainClarity fetches transaction data from public explorers (Etherscan for Ethereum, Solscan Pro for Solana), turns the raw response into bounded structured evidence, and — when you ask a question about the transaction — sends the claim + evidence to a GenLayer Intelligent Contract. Validator consensus independently re-evaluates whether the evidence actually supports your claim, and the verdict (SUPPORTED / CONTRADICTED / INSUFFICIENT_EVIDENCE) is stored on-chain and retrievable by anyone.

The contract never treats the explorer API as verified truth and never accepts a single node's conclusion without its own evaluation — that independent adjudication is the role of GenLayer consensus here.

Limitations

  • Explorer APIs can be delayed, rate-limited, or wrong. A success status means the transaction executed — it does not mean it was safe, honest, or what you intended.
  • Evidence is provider-reported (Etherscan / Solscan), not independently re-verified on-chain by this application.
  • Token transfers beyond native ETH/SOL are shown only when the provider's response reliably contains them; otherwise they are listed as missing.
  • Wallet-address analysis is not supported yet.
  • GenLayer consensus evaluates the evidence as submitted; it cannot fetch explorers itself in this version.

Privacy & API disclosure

  • No wallet connection, no signatures, no private keys — analysis is read-only.
  • The hash you submit and your optional question are sent to the ChainClarity API and, if you asked a question, stored on the public GenLayer testnet as part of the adjudication record. Do not paste a question containing personal data.
  • Provider API keys are server-side only and are never sent to your browser.
  • No accounts, cookies, or third-party analytics.
